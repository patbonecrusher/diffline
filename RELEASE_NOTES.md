Diffline 1.0 — a native macOS diff and merge tool.

- Side-by-side file comparison with aligned rows, word-level highlighting, and wrapped lines that stay aligned
- Syntax coloring for 24 languages
- Merge changes left or right with Undo, then save
- Three-way merge (base, mine, theirs) with automatic resolution of non-overlapping changes; works as `git mergetool`
- Folder comparison with added / removed / modified status and drill-in
- Whitespace, case, and blank-line options; unified diff export
- Finder service, Dock drops, and a `diffline` command-line tool (File > Install Command Line Tool…)

Requires macOS 14 or later. Sandboxed, notarized, no network access.

Homebrew: `brew install --cask patbonecrusher/tap/diffline`
