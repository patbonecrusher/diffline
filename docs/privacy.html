Privacy Policy

Effective 13 October 2026

In short: Diffline runs on your Mac and nowhere else. It collects nothing, sends nothing, and the developer never receives your files or anything about how you use the app.

Who this covers

This policy describes how the Diffline application for macOS ("Diffline", "the app") handles information. Diffline is developed and maintained by an individual developer ("the developer"). It applies to every way of getting the app: the Mac App Store, the direct download, and Homebrew.

Information Diffline collects

None. Diffline has no accounts, analytics, telemetry, crash reporting, or advertising, and it makes no network connections.

Files you open

Diffline runs inside the macOS App Sandbox. It can read only the files and folders you choose, drop on it, or hand to it from Finder or the diffline command, and it writes only when you save a merge or export a diff. File contents are processed in memory on your Mac and are never transmitted.

Information stored on your Mac

DataWhyHow to remove it
Recent comparisonsTo reopen them from the start window. Stored as macOS security-scoped bookmarks, which record where the items are.Click Clear under Recent on the start window.
PreferencesFont size, comparison options and similar settings.Delete the app, or remove ~/Library/Containers/com.patlaplante.Diffline.

This data lives in the app's own sandbox container on your Mac. It is not synced or shared.

The command-line tool

The optional diffline command is a short shell script that passes file paths to the app through macOS's open command. It does not collect or send anything.

Third parties

Diffline contains no third-party code and shares nothing with anyone. If you download Diffline from the Mac App Store, GitHub or Homebrew, those services' own privacy policies cover the download itself.

Children

Diffline does not collect personal information from anyone, including children.

Changes

If Diffline's handling of information ever changes, this page will be updated before the release that changes it, and the effective date above will change.

Contact

Questions about this policy can be sent to the developer through GitHub Issues.
